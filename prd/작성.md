# 작성

- **출력 형식**: 역할지정형
- **담당**: 담당자 조연익

## 전용 축

### 축 1 — 목적
- 선택 방식: 중복 선택(체크박스) — 좌(정보 전달/보고)와 우(요청/승인)가 한 문장에서 동시에 참일 수 있음(예: "보고드리며 승인도 요청드립니다")
- 좌: 정보 전달/보고하기 / 우: 요청/승인받기
- 좌 신호 키워드(명사 어근, 조사 무관 매칭 전제): 보고, 전달, 공유, 완료, 결과, 현황, 공지
- 좌 신호 키워드(구문형, 그대로 매칭): 알려드립니다, 진행 상황
- 우 신호 키워드(명사 어근, 조사 무관 매칭 전제): 요청, 결재
- 우 신호 키워드(구문형, 그대로 매칭): 승인해 주세요, 검토 부탁, 허락받고 싶은데, 해주실 수 있을까요, 도와주세요, 협조 부탁
- 기본값: 좌 (정보 전달/보고하기)
- 매칭 참고: 명사 어근 키워드(보고·전달·공유·완료·결과·현황·공지·요청·결재)는 순수 명사라 조사가 붙어도(보고서·보고드립니다·전달할게요 등) 각 어절이 이 어근으로 시작하는지(startsWith)만 확인하면 조사·활용형과 무관하게 감지된다. 반면 구문형 키워드(승인해 주세요·검토 부탁·허락받고 싶은데 등)는 짧은 문장 조각이라 어근화하지 않고 나열된 형태 그대로 매칭한다 — 두 그룹을 한 방식으로 뭉뚱그리면 "보고" 같은 순수 명사까지 활용형을 못 잡게 되므로 반드시 구분해서 구현한다.

### 축 2 — 대상
- 좌: 상급자/외부인 / 우: 동료/팀원
- 좌 신호 키워드: 사장님, 임원진, 본부장, 과장, 팀장, 거래처, 외부, 고객, 클라이언트, 상사
- 우 신호 키워드: 팀원, 동료, 같은 팀, 우리 팀, 후배, 옆 부서, 같은 직급, 누나, 언니, 오빠
- 기본값: 좌 (상급자/외부인)
- 매칭 참고: 우 신호는 순수 명사 형태이며, 조사 결합 시("팀원이", "동료와", "후배가" 등) 변형이 규칙적이므로 명사 어근만 등록하고 구현 시 각 단어가 이 어근으로 시작하는지(startsWith) 확인하면 조사와 무관하게 전부 감지됩니다.

### 축 3 — 문서 유형
- 좌: 간단한 형식(이메일/메신저) / 우: 체계적 형식(회의록/보고서/기획서)
- 좌 신호 키워드: 이메일, 메시지, 메신저, 카톡, 슬랙, 한두 줄, 빠르게, 간단히
- 우 신호 키워드: 회의록, 보고서, 기획서, 제안서, 문서, 형식, 체계, 상세, 첨부
- 기본값: 좌 (간단한 형식)
- 매칭 참고: 우 신호에 포함된 "형식", "체계" 같은 어근("형식", "체계", "상세")으로 구현 시 각 단어가 이 어근으로 시작하는지 확인하면("형식"으로 시작하는 "형식적"·"형식적으로" 등), 조사와 활용형을 자동으로 감지할 수 있습니다.

## 고정 규칙

```
고정_규칙: [
  { 조건: "상급자, 외부인", 문구: "공손한 말투: 상사나 고객에게 적합한 존댓말을 사용해요." }
]
```

## 겹침 처리 규칙

- 축1(목적)은 중복선택 축이라 이 규칙 대상이 아님 — 감지된 좌/우 신호를 모두 반영한다(양쪽 다 토글 가능).
- 축2(대상)·축3(문서 유형) 등 단일선택 축에서 좌/우 신호가 동시에 감지되면, 원문 전체 텍스트에서(문장 구분 없이) 더 나중에 등장한 신호를 우선 채택.
