# /schemas — 카테고리 스키마 취합

Yahoo_Prompt의 5개 카테고리 전용 축·키워드 사전·고정 규칙을 정리한 폴더입니다. 스키마 형식은 루트 [`README.md`](../README.md)의 "카테고리 설정 스키마" 섹션을 따릅니다.

```
카테고리 설정 = {
  이름,
  출력_형식: "역할지정형" | "태그나열형",
  전용_축: [ {축_이름, 선택지, 키워드사전, 기본값(, 효과)}, ... ],
  고정_규칙: [ {조건: "항상" | "축_이름=값", 문구}, ... ]
}
```

## 카테고리 간 공통 규칙

- **공통 축 없음**: 모든 카테고리가 공유하는 전역 축은 없습니다. 각 카테고리는 전용 축만으로 구성됩니다.
- **겹침 처리 규칙**: 5개 카테고리 전부 동일하게, 한 축 내에서 좌/우(또는 다중 선택지) 신호가 동시에 감지되면 **문장에서 더 나중에 등장한 신호를 우선 채택**합니다.
- **자유 슬롯(지명, 고유명사 등) 미지원**: 정해진 키워드로 판별할 수 없는 값(예: 여행지명)은 규칙 엔진으로 감지하지 않고, 자연어 입력창의 placeholder 문구로 유도합니다.
- **조건부 고정 규칙**: "항상 적용"과 "특정 축=값일 때만 적용"을 하나의 배열로 통일해서 표현합니다.
