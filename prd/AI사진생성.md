# AI 사진생성

- **출력 형식**: 태그나열형 (`[사용자 원문], tag1, tag2, ...` 방식으로 조립)
- **담당**: 담당자 조연익

## 전용 축

### 축 1 — 가로세로비율 (텍스트 자동감지 없음, 사용자 수동 선택 전용, 기본값 없음)
- 옵션(표시 순서 그대로, 4지선다): 기본(3:4), 와이드스크린(16:9), 가로(4:3), 정사각형(1:1)
- **기본값 없음** — 다른 3개 축(스타일/피사체/구도)은 감지 실패 시 항상
  옵션 목록 1번째로 자동 채워지지만, 이 축은 그마저도 없다. 세부 조정에
  처음 나타날 때 4개 옵션 중 아무것도 선택돼 있지 않은 상태(전부 비활성
  표시)로 시작하며, 사용자가 하나를 직접 클릭해야만 값이 채워진다.
- 다른 축과 달리 원문 텍스트에서 키워드로 감지하지 않는다 — 신호 키워드가
  없고, 항상 사용자가 세부 조정에서 직접 클릭해서 골라야 하는 값이다(글로
  아무리 "정사각형으로"라고 써도 자동으로 안 바뀜).
- 세부 조정 UI에서 다른 3개 축보다 위, 가장 첫 번째 축으로 표시된다.
- 태그 조립 시 선택된 옵션의 표시 문구를 다른 축과 동일하게 그대로 태그로
  사용한다(예: "와이드스크린(16:9)").
- **AI사진생성 카테고리만의 예외 규칙**: 이 축에 값이 선택되기 전까지는
  완성된 프롬프트 자체를 만들지 않는다(다른 4개 카테고리는 축이 전부
  기본값을 갖고 있어서 텍스트만 있으면 바로 프롬프트가 만들어지지만, 이
  카테고리는 가로세로비율을 고르기 전까진 결과가 비어있어야 함). 완성된
  프롬프트가 비어있으면 복사·바로 보내기 버튼도 함께 비활성 상태를
  유지한다.

### 축 2 — 스타일
- 좌: 사진 같은 현실적 / 우: 일러스트/만화/추상적
- 좌 신호 키워드: 사진, 현실적, 포토리얼, 실제, 3D 렌더링, 사실적
- 우 신호 키워드: 일러스트, 만화, 카툰, 드로잉, 손그림, 추상적, 판타지, 컨셉아트, 스타일라이즈, 애니메이션, 수채화
- 기본값: 좌 (사진 같은 현실적)

### 축 3 — 주요 피사체
- 좌: 인물 중심 / 우: 인물 중심 아님(풍경·물건·동물)
- 좌 신호 키워드: 사람, 인물, 초상화, 인물 사진, 사람 사진, 여성 인물, 남성 인물, 인물 포즈, 패션모델, 모델 사진
- 우 신호 키워드: 풍경, 자연, 건물, 물건, 제품, 동물, 강아지, 고양이, 숲, 바다, 도시, 음식
- 매칭 참고: "자연"은 명사 어근(startsWith)으로 매칭하지만, "자연스럽/자연스러운/자연스럽게" 등 "자연스럽-"으로 이어지는 활용형은 제외한다(사람 묘사에 흔한 "자연스럽게"가 우 신호로 오탐하는 것을 막기 위함).
- 기본값: 좌 (인물 중심)

### 축 4 — 구도/프레이밍
- 좌: 클로즈업(피사체의 일부·세부 중심) / 우: 광활한 뷰(전체·배경 중심)
- 좌 신호 키워드: 클로즈업, 확대, 세부, 근접, 헤드샷, 디테일
- 우 신호 키워드: 멀리서, 광각, 전체 샷, 배경 포함, 전경, 넓게, 드넓은, 와이드 샷, 광활
- 기본값: 우 (광활한 뷰)

## 고정 규칙

```
고정_규칙: [
  { 문구: "상업용으로 이용할 경우 생성된 이미지는 이용 전 해당 AI 서비스의 이용 약관과 저작권 정책을 확인하세요." },
  { 문구: "더 정확한 결과를 위해 인물의 나이대, 성별, 표정, 스타일을 함께 적어주시면 좋아요." }
]
```
## 태그 조립 원칙

가로세로비율(사용자 선택값) 1개 + 스타일/피사체/구도 각 축에서 감지된(또는
기본값) 신호 1개씩, 총 4개의 태그가 항상 이 순서로 조립됩니다.

## 겹침 처리 규칙

한 축 내에서 좌/우 신호가 동시에 감지되면, 원문 전체 텍스트에서(문장 구분 없이) 더 나중에 등장한 신호를 우선 채택.

## 참고 — 다른 카테고리와의 조립 방식 차이

다른 4개 카테고리(역할지정형)는 "당신은 ~입니다. ~해주세요" 문장으로 조립되지만, 이 카테고리는 `[사용자 원문], 태그1, 태그2, ...` 형태로 조립됩니다. 결과 확인 화면에서도 이 카테고리에 한해 "이미지 생성 AI(Midjourney, DALL·E, Gemini 이미지 생성 등)에 붙여넣으세요"로 안내 문구가 달라집니다.
